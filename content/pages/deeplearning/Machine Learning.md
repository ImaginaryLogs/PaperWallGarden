There are major types of learning:
- [[Supervised Learning]]: Learning from labeled examples (Input + Answers) to perform tasks like: 
	- [[Regression]] - predicting continuous values, and 
	- [[Classification]] - categorical labeling
- [[Unsupervised Learning]]: Finding hidden patterns in unlabeled data, such as [[Clustering]] or [[Dimensionality Reduction]]
- [[Self-Supervised Learning]]: Generating labels from the data itself via pretext tasks (e.g. mased modeling)
- [[Semi-Supervise Learning]]: Combining small amounts of labeled data with massive unlabeled datasets using techniques lie [[Pseudo-Labeling]]
- [[Reinforcement Learning]]: An agent-environment loop where the agent learns to maximize cumulative Rewards through trial and errors.
