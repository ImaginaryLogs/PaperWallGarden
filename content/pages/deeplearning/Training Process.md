[[Forward Propagation]]: Passing inputs through the network layers to calculate an output.

[[Backward Propagation]]: Using the [[Chain Rule]] to compute gradients of the loss function with respect to weights, allowing the model to learn.

[[Optimization Algorithms]]: The engine for adjusting parameters, including [[Gradient Descent]], [[Stochastic Gradient Descent]], and adaptive techniques like [[Adam]] or [[[Momentum]]
